Installer Trackr en 4 étapes.

Aucun compte, aucune configuration technique.

  1. Télécharge l'installateur Trackr-Setup-x.y.z.exe depuis la dernière release.
  2. Lance-le, choisis le dossier d'installation et le style de « Partie en cours » (Duel, Cartes ou Tableau), puis clique sur Installer.
  3. Ouvre Trackr depuis le menu Démarrer et laisse le client League of Legends ouvert : le compte et les phases de jeu sont détectés automatiquement.
  4. Active les options qui t'intéressent dans les réglages : import automatique des runes, acceptation automatique, Discord.

Windows peut afficher un avertissement au premier lancement : télécharge toujours Trackr depuis la page de release officielle. Les mises à jour se font ensuite depuis l'application, avec le bouton « Mettre à jour Trackr ». Un souci ? Les journaux sont dans %APPDATA%\Trackr\logs.
